# Challenge 02: TripCalc "Plan the Trip. Calculate the Cost"

# Problem Description
A student is planning a road trip. Write a C program to read the total distance to be travelled (in kilometres), the vehicle's mileage (kilometres per litre), and the current fuel price per litre. Calculate and
display the amount of fuel required for the trip and the total fuel cost.

# Program Objectives
* Practice basic input/output operations using printf() and scanf() in C.
* Use int and float keyword (data type).
* Apply fundamental arithmetic operators (/, *) for formula evaluation.

# Logic & Formulas
1. fuel requried: distance / mileage.   
2. total fuel cost: fuel required * fuel price .

3. Calculate the fuel required = distane/mileage.
