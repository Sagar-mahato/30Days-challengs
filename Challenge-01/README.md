# Challenge 01: Calculate Total, Average, and Percentage Marks

# Problem Description
This program reads the marks of five subjects entered by the user, calculates the total marks, average marks, and overall percentage, and displays all three results formatted to two decimal places[span_1](start_span)[span_1](end_span).

# Program Objectives
* Practice basic input/output operations using printf() and scanf() in C.
* Use float keyword (data type).
* Apply fundamental arithmetic operators (+, /, *) for formula evaluation.

# Logic & Formulas
1. Total Marks:* Sum of marks obtained across all 5 subjects.
   Total = sub1 + sub2+ sub3 + sub4 + sub5

2. Average Marks: Total marks divided by the total number of subjects (5).
   Average = Total/5

3. Percentage: Ratio of total marks obtained to maximum total marks (500) and multiple by 100.
   Percentage = (Total/500) * 100

# Alogrithm
1. Start
2. Read the marks of the five subjects.

4. Calculate the average marks.
